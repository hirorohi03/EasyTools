 # Overview
Use the following five types of batches.
- GitHub_CloneOrPull.bat
- GitHub_CloneOrPull_Hash.bat
- GitHub_CloneOrPull_Tag.bat
- GitHub_CloneOrPull_Folder_Hash.bat
- GitHub_CloneOrPull_Folder_Tag.bat

Note: GitHub_CloneOrPull.bat and GitHub_CloneOrPull_Hash.bat are exactly the same. (Created by [@Zuntan03](https://github.com/Zuntan03))

 # Relationships Between BAT Files
```
GitHub_CloneOrPull ─────────────┬─ Git_CloneOrPull ─ Git_SetPath
GitHub_CloneOrPull_Hash  ───────┤
GitHub_CloneOrPull_Tag ─────────┤
GitHub_CloneOrPull_Folder_Hash ─┤
GitHub_CloneOrPull_Folder_Tag  ─┘
```
